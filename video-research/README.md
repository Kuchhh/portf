# Разбор референсных роликов

Здесь копятся наблюдения по коротким рекламным роликам, которые присылает дизайнер. Главное внимание уделяется **ракурсам и движению камеры**. Из этих заметок потом соберём скилл с правилами коротких рекламных роликов, а по нему будем писать промпты для Seedance.

## Правила камеры (черновик, пополняется)

1. **Со спины камера привязана к герою.** Фигура стоит в одной точке кадра, мир едет навстречу. Наезд фона 15–26%/с, герой смещается меньше чем на 1,5% ширины кадра. *(01)*
2. **Качка мягкая, как у стабилизатора.** Вертикальная волна 2–5% высоты кадра медленнее шагов, крен до ±1,5°. Качается мир вокруг героя, не сам герой. Никакой дрожащей ручной съёмки. *(01)*
3. **Режим камеры следует за действием.** Герой идёт: сопровождение с качкой. Платит или берёт товар: камера замирает. Едет: камера едет вместе, без качки. *(01)*
4. **Склейка по герою.** На стыке планов голова и фирменная деталь стоят в той же точке кадра, меняется только локация. Получается одна непрерывная прогулка. *(01)*
5. **Один фирменный цветовой акцент на герое** (шарф цвета логотипа) узнаётся в каждом кадре со спины. *(01)*
6. **Лицо держим в «рамке»**: сверхкрупно в первом и последнем кадре, в середине только спина. *(01)*

## Инструмент

`camera_motion.py` измеряет движение камеры по каждому плану: панорама, наклон, крен, наезд, качка, смещение героя.

```bash
pip install --user opencv-python-headless
python3 video-research/camera_motion.py ролик.mp4 [--extra-cuts 4.27]
```
