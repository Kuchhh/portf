Файлы `gpt-prompts.md` — готовые инструкции для Claude в десктоп-приложении. Он генерирует в ChatGPT листы персонажей, предметов, локаций и раскадровку. Потом будут ключевые кадры и Seedance 2.0 («Виви»).

**Текущая версия — v4 (04.10.2026):**
- цвет и фотостиль по пяти стилевым референсам дизайнера (REF-STYLE-A…E);
- игра актёров по разбору эмоций (`video-research/06-emotions.md`);
- фотостиль как у Яндекса;
- палитра бренда в одежде и предметах;
- элегантная коза в голубых очках.

**Как пересобрать.** `gpt-prompts.md` не правим руками, они собираются из `spec.py` каждого ролика:

```bash
python3 video-projects/_kit/build_prompts.py --export <папка>
```

- Общие блоки — раскладки листов, фотостиль, палитра, правила — лежат в `_kit/`. Правка там меняет оба ролика сразу.
- `--export` кладёт копии с русскими именами: `Промпты_Развитие_…_v4.md` и `Сториборд_Развитие_…_v4.md`.
