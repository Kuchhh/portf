# «6 из 45»: подбор комбинации по всему архиву тиражей

Программа скачивает все тиражи лотереи «6 из 45» с stoloto.ru, проверяет их и выдаёт комбинации на следующий тираж. Она выбирает и тираж, в который ставка выгоднее всего.

Архив полный: с тиража №1 (10.11.2008), на 04.11.2026 это 19 313 тиражей. В каждом тираже записаны выпавшие шары по порядку, число ставок, число победителей и выплаты по каждой категории. Источник — тот же API, из которого грузит данные страница [stoloto.ru/6x45/archive](https://www.stoloto.ru/6x45/archive).

## Сайт

**https://kuchhh.github.io/portf/** — та же программа в браузере, ничего устанавливать не нужно.

Страница показывает:
- комбинации;
- выгоду по времени тиража и отсчёт до ближайшего тиража;
- стратегию для каждого режима выплат;
- популярность чисел;
- проверку случайности и бэктест.

Сайт обновляется сам:
- **на сервере.** Каждые 30 минут GitHub Actions (`.github/workflows/update.yml`) докачивает тиражи этой же программой, пересобирает страницу и публикует её;
- **в браузере.** При открытии страница загружает свежий `draws.json`. Если в нём есть тиражи новее расчёта, она пересчитывает комбинации и выгоду по времени прямо в браузере. Лучший тираж на ближайшие сутки пересчитывается каждую минуту.

Сам браузер скачать тиражи со stoloto.ru не может: Столото отдаёт данные только своему сайту. Поэтому их скачивает сервер GitHub.

| Файл | Что это |
|---|---|
| `web/engine.js` | расчёт: тот же метод, что в `gosloto645.py`, на JavaScript |
| `web/app.html` | шаблон страницы |
| `web/build.js` | сборка: `node web/build.js --out ..` кладёт `index.html` и `draws.json` в корень репозитория |

## Запуск на компьютере

Нужен Python 3.8 или новее, дополнительные библиотеки не нужны. Скачать его можно на [python.org](https://www.python.org/downloads/), при установке на Windows поставьте галочку «Add Python to PATH».

- **Windows:** дважды щёлкните `run_windows.bat`.
- **macOS / Linux:** `python3 gosloto645.py`

При каждом запуске программа сама:
1. докачивает новые тиражи (архив уже лежит рядом в `draws_6x45.csv`, поэтому это пара секунд);
2. проверяет случайность тиражей;
3. учит модель выбора других игроков;
4. читает действующие правила выплат и определяет режим;
5. выдаёт комбинации и выгоду по времени тиража.

| Команда | Что делает |
|---|---|
| `python gosloto645.py` | обновить архив и выдать 3 комбинации |
| `python gosloto645.py predict -n 10` | 10 комбинаций; они пересекаются не больше чем по 2 числа |
| `python gosloto645.py predict --bets 200` | учесть, что вы покупаете 200 ставок в один тираж |
| `python gosloto645.py predict --offline` | без интернета, по сохранённому архиву |
| `python gosloto645.py backtest` | проверка метода на прошлых тиражах (около 30 с) |
| `python gosloto645.py analyze` | только проверка случайности |
| `python gosloto645.py update` | только обновить архив |

## Метод

Программа ищет отклонения в нашу сторону в трёх местах.

**1. Выпадение чисел.** Проверяется вся база:
- частоты 45 чисел;
- частоты по позиции шара;
- частоты 990 пар;
- связь с прошлым тиражом.

Отдельно проверяется прогноз «тираж за тиражом»: для каждого тиража частоты считаются только по тиражам до него, с разной длиной памяти. Если какой-нибудь прогноз когда-нибудь начнёт угадывать лучше случая, программа сама переключится на него.

Сейчас отклонений нет: частоты чисел p = 0,48, пары p = 0,51, а лучший прогноз по частотам угадывал хуже равных шансов.

**2. Выбор других игроков.** В каждом тираже известно, сколько людей угадали 2, 3 и 4 числа. Если выпали популярные числа, победителей больше обычного, если непопулярные — меньше. По 19 тысячам тиражей программа выучила:
- **какие числа популярны.** Чаще всего ставят 7, 11, 13, 3, 17, 8, 5, 23 — «счастливые» числа и даты. Реже всего — 36–45 и 1;
- **какие сочетания люди обходят.** Например, два числа подряд.

Свежие тиражи весят больше старых, «полупериод» около 1500 тиражей. Его длина подобрана проверкой на будущих тиражах. На тиражах, которых модель не видела, она объясняет 44% разброса числа победителей за 2 числа и 35% за 3.

С 2 ноября 2026 года призы за 2, 3 и 4 числа делятся между всеми победителями тиража. Поэтому комбинация, которую мало кто ставит, при выигрыше получает больше. Программа подбирает такие комбинации и не берёт узоры, которые люди рисуют на билете: три числа подряд, арифметические ряды, столбцы и недавние выигрышные комбинации.

**3. Выбор тиража.** По нынешним правилам фонд каждой делимой категории состоит из постоянной части и доли с каждой ставки:
- за 2 числа: около 213 тыс. ₽ + 10,55 ₽ с каждой ставки;
- за 3 числа: около 58 тыс. ₽ + 12,54 ₽ с каждой ставки;
- за 4 числа: около 15 тыс. ₽ + 4,61 ₽ с каждой ставки.

Постоянная часть одинакова в любом тираже. Поэтому в тиражах с малым числом ставок на одну ставку приходится больше. Программа сама находит в последних тиражах, когда менялись правила, заново вычисляет эти формулы и показывает выгоду по времени тиража.

## Когда раздача закончится

Программа и сайт определяют режим выплат по последним тиражам и сами меняют стратегию.

| Режим | Как платят | Какие комбинации | Когда играть |
|---|---|---|---|
| **Раздача** (сейчас) | призы за 2–4 числа делятся между победителями, к каждому тиражу добавляется постоянная сумма из фонда | те, что реже ставят другие | в тиражи с малым числом ставок |
| **Делимые призы без добавки** | призы за 2–4 числа делятся, добавки нет | те, что реже ставят другие | время не важно; окупается только при большом суперпризе |
| **Обычный** | фиксированные призы за 3–5 чисел, суперприз копится | шестёрки, которые реже всех ставят другие | только при суперпризе выше порога окупаемости |

До 2 ноября 2026 года действовал обычный режим: за 3 числа платили 1 750 ₽, за 4 — 2 800 ₽, за 5 — 100 000 ₽, а суперприз копился. Скорее всего, после раздачи игра вернётся к нему.

**Какие комбинации.** В обычном режиме номера не меняют ни шанс выиграть, ни призы за 3–5 чисел. Они влияют на одно: придётся ли делить суперприз, если он выпадет. Поэтому программа ищет шестёрки, которые другие игроки ставят реже всех. Как часто люди ставят целую шестёрку, она узнаёт из той же модели: популярность каждого числа и узоров вроде двух чисел подряд. Например, 34 37 38 40 42 45 ставят в 2,5 раза реже средней шестёрки. С ней суперприз пришлось бы делить в 0,12% случаев, со средней — в 0,30%.

**Когда играть.** Выгода в обычном режиме зависит только от суперприза, время тиража на неё почти не влияет. При тех призах ставка в 70 ₽ окупается в среднем, только если суперприз больше ≈196 млн ₽. При обычных ≈26 млн ₽ она возвращает около 0,70 ₽ на рубль. За последние три года суперприз не поднимался выше ≈90 млн ₽. Поэтому в обычном режиме программа показывает порог и подсказывает, стоит ли ставить.

## Проверка на прошлых тиражах

Команда `backtest` проверяет метод на тиражах №5001–№19315 (14 313 тиражей). Модель переобучается каждые 1000 тиражей и видит только прошлое. На каждый тираж выставляется по 10 билетов каждой стратегии.

| Стратегия | Угадано 2, доля | Угадано 3, доля | Приз за 2 | Приз за 3 | Приз за 4 | Выплата за 2–4 на билет* |
|---|---|---|---|---|---|---|
| теория | 0,15147 | 0,02244 | | | | |
| **против толпы (этот метод)** | 0,15478 | 0,02345 | ×1,039 | ×1,147 | ×1,445 | **×1,099** (1,079…1,117) |
| случайные билеты | 0,15213 | 0,02211 | ×1,005 | ×1,022 | ×1,100 | ×1,000 |
| самые популярные | 0,14910 | 0,02162 | ×0,972 | ×0,904 | ×0,829 | ×0,911 (0,897…0,923) |
| «горячие» числа | 0,15192 | 0,02297 | ×1,004 | ×1,015 | ×1,015 | ×0,987 (0,970…1,004) |
| «холодные» числа | 0,15141 | 0,02138 | ×1,006 | ×1,026 | ×1,103 | ×1,002 (0,986…1,018) |

\* По нынешним правилам, к выплате случайного билета, при теоретической частоте попаданий. В скобках 95% интервал.

- **Частота попаданий** у всех стратегий в пределах случайного разброса. У «против толпы» она выше теории на 0,9 стандартного отклонения: так получилось, потому что числа 36, 43 и 40 выпадали в эти годы чуть чаще.
- **Размер приза** у «против толпы» стабильно выше, чем у случайных билетов: за 2 числа на 3%, за 3 на 12%, за 4 на 31%, в сумме на 10%.
- **При старых правилах** с фиксированными призами преимущества не было: ×1,016 (0,909…1,128).

## Как читать вывод

Пример на 04.11.2026:

```
4. Комбинации на следующий тираж:
   36 37 39 40 44 45   приз при выигрыше: за 2 ×1,04, за 3 ×1,13, за 4 ×1,48

5. Сколько в среднем возвращает одна ставка (до налогов), по времени тиража:
   время   ставок   обычный билет   билет №1   на 1 ₽
   11:00    42802        45,5 ₽      50,3 ₽   0,72
   19:40     7543        76,7 ₽      84,1 ₽   1,20  ←

6. Когда раздача закончится, призы, скорее всего, снова станут фиксированными, как до тиража №19282:
   …ставка будет окупаться только при суперпризе от 195 767 200 ₽; за три года он доходил до 89 814 980 ₽.
```

- **«×1,13»** — во сколько раз приз этой комбинации за 3 числа в среднем больше обычного.
- **«на 1 ₽»** — средний возврат на рубль ставки, вместе с долей суперприза.
- **Стрелка** отмечает тиражи, где возврат не меньше цены ставки.

Сейчас это небольшие тиражи в 14:40, 14:55, 19:40, 19:55 и 23:59.

В обычном режиме вместо множителей программа пишет, с какой вероятностью придётся делить суперприз и во сколько раз реже другие ставят эту шестёрку. Вместо таблицы по времени она показывает возврат при нынешнем суперпризе и порог окупаемости.

## Важно знать

- **Правила выплат с делёжкой призов действуют с 2 ноября 2026 года**, на момент написания по ним прошло 34 тиража. Постоянная часть фонда может уменьшиться или исчезнуть. Программа при каждом запуске заново читает правила по последним тиражам, поэтому таблица выгоды всегда актуальна.
- **Выгода — это среднее по большому числу ставок.** В одном тираже примерно 82% ставок не выигрывают ничего.
- **Ваши ставки увеличивают число ставок в тираже**, а значит уменьшают постоянную часть на каждую. Укажите `--bets`, и программа это учтёт.
- **Налоги в расчёте не учтены.**
- **Если Столото сменит ключ API**, программа найдёт новый на сайте сама.
