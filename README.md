# Лотереи Столото: «6 из 45» и «5 из 36»

- **«6 из 45» против толпы: https://kuchhh.github.io/portf/**
- **«5 из 36», игра на главные призы: https://kuchhh.github.io/portf/5x36/** — описание в [lotto-5x36/README.md](lotto-5x36/README.md)

Ниже — про «6 из 45».

Подбор комбинаций для лотереи «6 из 45» по всему архиву тиражей Столото с 2008 года. Сайт показывает, какие числа реже ставят другие игроки и в какой тираж ставка выгоднее всего.

## Как обновляется

- **Сервер.** Каждые 30 минут GitHub скачивает новые тиражи со stoloto.ru, пересчитывает комбинации и выгоду по времени тиража и заново публикует сайт. Это делает файл `.github/workflows/update.yml`.
- **Страница.** При открытии она загружает свежий архив. Если в нём есть тиражи новее расчёта, страница пересчитывает всё прямо в браузере. Отсчёт до ближайшего тиража и лучший тираж на ближайшие сутки обновляются каждую минуту.

## Стратегия в разных режимах выплат

Режим программа определяет сама по последним тиражам и сама меняет стратегию.

| Режим | Как платят | Какие комбинации | Когда играть |
|---|---|---|---|
| **Раздача** (сейчас, с 2 ноября 2026) | призы за 2–4 числа делятся между победителями, и к каждому тиражу добавляется постоянная сумма из фонда | те, что реже ставят другие: приз при выигрыше больше на 4–48% | в тиражи с малым числом ставок; список на сайте пересчитывается сам |
| **Делимые призы без добавки** | призы за 2–4 числа делятся, добавки нет | те, что реже ставят другие | время не важно; окупается только при большом суперпризе |
| **Обычный** (как до 2 ноября 2026) | фиксированные призы за 3–5 чисел, суперприз копится | шестёрки, которые реже всех ставят другие: если выпадет суперприз, его реже придётся делить | только при суперпризе от ≈196 млн ₽ |

В обычном режиме ставка окупается только при суперпризе от ≈196 млн ₽. За последние три года он поднимался максимум до ≈90 млн ₽, а при обычных ≈26 млн ₽ ставка возвращает около 0,70 ₽ на рубль.

## Файлы

- `index.html`, `draws.json` — сайт. Их собирает автообновление, руками их не правят.
- `5x36/` — сайт «5 из 36» (`index.html`, `state.json`), тоже собирается автоматически.
- `lotto-5x36/` — программа «5 из 36» на Python, архив тиражей и исходники её страницы.
- `lotto-6x45/` — программа для компьютера на Python, архив тиражей и исходники сайта. Метод и проверка на прошлых тиражах описаны в [lotto-6x45/README.md](lotto-6x45/README.md).
